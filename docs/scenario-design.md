# CRE 호흡기감염 격리환자 오류의 방 — 중간보고서(초안)

## 1. 개요
- **프로그램명**: CRE·호흡기감염 격리환자 오류의 방 (WebXR)
- **형태**: 웹 브라우저 / VR 헤드셋에서 실행하는 가상 격리병실 시뮬레이션
- **개발 도구**: Three.js, WebXR Device API, Vite, GitHub(형상관리·Pages 배포)
- **학습 대상**: (작성 필요 — 예: 간호학과 3·4학년, 신규 간호사)

## 2. 학습 목표
1. CRE 보균 환자에게 필요한 접촉주의 수칙을 설명할 수 있다.
2. 호흡기감염 환자에게 필요한 비말주의 수칙을 설명할 수 있다.
3. 두 가지 주의가 함께 필요한 격리병실 환경에서 감염관리·환자안전 오류를 찾아낼 수 있다.
4. 찾은 오류마다 올바른 수정 방법과 근거를 말할 수 있다.

## 3. 시나리오 설정
- **환자**: 김OO, 78세 남자. 요양병원에서 전원, 입원 시 선별검사에서 CRE 보균 확인. 폐렴으로 비말주의 시행 중.
- **장소**: 1인 격리병실 (문 안쪽에서 시작)
- **상황**: 학습자는 담당 간호사로서 근무 교대 후 처음 병실을 라운딩합니다. 제한시간 10분 안에 오류를 최대한 많이 찾습니다.

## 4. 오류 목록
| ID | 분류 | 오류 | 올바른 수행 |
|---|---|---|---|
| doorSign | 감염관리 | 접촉주의 표지만 있음 | 접촉·비말 표지 모두 부착 |
| ppeCart | 감염관리 | PPE 카트가 병실 안에 있음 | 입구 바깥(전실)에 두고 들어가기 전에 착용 |
| sanitizer | 손위생 | 손소독제 비어 있음 | 사용 위치에 항상 채워 두기 |
| stethoscope | 감염관리 | 공용 청진기 | 환자 전용 물품 사용 |
| wasteBin | 환경관리 | 폐기물 용기 뚜껑 열림·넘침 | 뚜껑 닫기, 기준 용량 전에 교체 |
| bedRail | 환자안전 | 침상 난간 내림 | 난간 올림, 침대 높이 낮춤 |
| wristband | 환자안전 | 환자 확인 팔찌 없음 | 팔찌 착용, 두 가지 식별자로 확인 |
| ivBag | 투약안전 | 수액 라벨 없음 | 환자명·약명·용량·시간·혼합자 라벨 부착 |

정상 물품(오답 유도): 창문, 산소 공급장치, 벽시계, 침상 옆 테이블

## 5. 상호작용·평가 설계
- **입력**: PC는 마우스 클릭, VR은 컨트롤러 레이 + 트리거
- **피드백**: 지목 즉시 정답/오답과 해설·근거를 보여줌 (PC는 HTML 카드, VR은 시야 앞 3D 패널)
- **점수**: 발견 1개당 10점, 오답 1회당 −2점
- **기록**: 지목 시각·대상·결과를 로그로 남김 → 사후 디브리핑과 연구 자료에 활용
